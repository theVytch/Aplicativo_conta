# Aplicativo_conta
Aplicativo feito para estudos. 

Um aplicativo simples, intuitivo e eficiente para gerenciar suas finanças pessoais. Com ele, você define um saldo inicial e registra cada gasto com nome, valor e data. Conforme as despesas são adicionadas, o saldo é automaticamente atualizado, oferecendo uma visão clara e em tempo real do seu orçamento. Além disso, o app permite gerar um relatório em PDF com todo o histórico de gastos, ideal para acompanhar seus hábitos financeiros e manter o controle no dia a dia.

## 🔧 Funcionalidades

✅ Adicionar saldo inicial  
✅ Registrar novos gastos com:
- Nome do gasto
- Valor
- Data

✅ Atualização automática do saldo restante  

✅ Widget para adicionar na tela inicial

✅ Visualização de todos os gastos adicionados  

✅ Geração de relatório em **PDF** com todos os gastos registrados
